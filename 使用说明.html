桌面效率小工具

便签 / Planbook 使用说明

一个轻量的桌面待办应用：日历规划 + 透明置顶便签 + 未完成清单，支持 macOS 与 Windows。

1主界面：日历 + 当日计划

打开应用后默认看到两大块：

  • 左侧日历：按月份查看，日期上的小圆点表示当天有安排；点击任意日期即可切换到那一天。
  • 右侧当日计划：显示选中日期的所有待办事项，可在这里添加、完成、删除。
今日安排会自动同步到右侧面板；切换日期不会丢失任何数据，所有计划都按日期分别保存。

2添加 / 完成 / 删除计划

  • 添加：在右侧输入框填写内容，按 Enter 或点“添加”按钮即可；可顺手带一个简短备注（用 内容（备注） 的写法会自动拆分，或在输入框下方填写备注）。
  • 完成：点击事项前的圆圈，勾选即视为已完成（会自动从“未完成”清单中消失）。
  • 删除：悬停到某条事项，点右侧的 ✕ 删除。

3顶栏按钮一览

未完成
按日期列出所有还没做完的事项。日期标签用颜色区分：红色为历史、蓝色为未来。点日期可跳到日历对应那一天，点圆圈可直接标记完成。
钉桌面
把“今日任务”变成一个透明、始终置顶的小窗挂在桌面上（详见第 4 节）。再次点击可关闭。
节假日
联网更新当年及往年的法定节假日与调休安排，日历会自动标出放假 / 补班。
模板 / 导入 / 导出
下载示例模板、从文件导入计划、或把当前所有计划导出为 JSON 备份。

4桌面便签窗口（钉桌面）

点顶栏 钉桌面 后，会弹出一个透明、始终在最上层的小窗口，贴在桌面上随时可见、不打扰你操作其他软件。

怎么用

  • 移动：在窗口空白处按住拖动即可。
  • 改变大小：把鼠标移到窗口右下角 / 右边 / 下边边缘，出现可拉伸光标后拖动。
  • 添加任务：在底部输入框填写，按 Enter 保存。
  • 完成 / 删除：和主界面一样，点圆圈勾选、点 ✕ 删除。
  • 关闭便签：点窗口右上角 ✕，或按 Esc 键；也可以在顶栏再次点“关闭便签”。
便签与主窗口实时互相同步：在便签里勾掉的任务，主界面立刻更新；在主界面改的计划，便签也会自动刷新（每 3 秒同步一次）。两个窗口共享同一份数据，不会冲突。
Windows 提示：在 Windows 上，便签为透明窗口；极少数情况下若系统未提供真正的窗口透明，会自动退化为“半透明深色面板”，文字依然清晰可读。按钮文字配色已针对该场景优化。

5节假日与调休

点顶栏 节假日：

  • 方式一（推荐）：填入年份（如 2027），点“拉取该年数据”，自动联网获取国务院放假安排。
  • 方式二（联网失败时用）：手动打开数据源地址，复制返回的 JSON，粘贴到文本框后“导入粘贴内容”。

更新后，日历上会标注放假（休）与补班（班），方便你排期。

6导入 / 导出 / 备份

  • 模板：下载一个示例 JSON 到本地，照着格式填好你的计划后，用“导入”读回。
  • 导入：选择一个本地 JSON 文件，替换 / 载入其中的计划。
  • 导出：把所有计划导出为一个 JSON 文件，便于备份或换设备迁移。

7数据与文件位置

所有数据保存在本机，不会上传到任何服务器：

  • macOS：~/Library/Application Support/com.planbook.planner/
  • Windows：C:\Users\你的用户名\AppData\Roaming\com.planbook.planner\

该目录下主要有：

  • 计划数据：plans.json
  • 节假日数据：holidays.json

重装应用不会自动删除这些文件；如需彻底清空，手动删除上述目录即可。

8小结与建议

  • 日常规划：用左侧日历 + 右侧面板安排每天的事。
  • 碎片执行：工作学习时把“今日任务”钉到桌面，随时看、随手勾。
  • 周末复盘：点“未完成”，集中处理历史遗留，再用颜色一眼分清轻重缓急。
  • 换机 / 备份：定期“导出”，需要时用“导入”恢复。
